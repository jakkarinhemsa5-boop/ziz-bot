สรุปการทำงานของโค้ด POP (Integrated 8-Step Ward Patrol Robot & IV Bag Volume Detection)

ไฟล์ ppppp_main.py (หรือโปรเจกต์ POP) เป็นโค้ดควบคุมหุ่นยนต์ลาดตระเวนในหอผู้ป่วยแบบ 8 ขั้นตอน พร้อมระบบประมวลผลภาพเพื่อตรวจสอบปริมาตรน้ำเกลือ (IV Bag) ในตัว โดยทำงานร่วมกับบอร์ด Arduino, กล้องวิดีโอ และเซนเซอร์อัลตราโซนิก (Sonar)

โครงสร้างและส่วนประกอบหลัก

  1. ระบบขับเคลื่อนล้อ Mecanum (Mecanum Wheels): ควบคุมมอเตอร์ 4 ตัว (ซ้ายหน้า, ขวาหน้า, ซ้ายหลัง, ขวาหลัง) ทำให้สามารถเคลื่อนที่ได้อิสระ ทั้งเดินหน้า ถอยหลัง เลี้ยว และสไลด์ออกด้านข้างซ้าย-ขวาได้
  2. ระบบหลบหลีกสิ่งกีดขวาง (Obstacle Avoidance): ใช้เซนเซอร์ Sonar ในการวัดระยะทาง หากพบสิ่งกีดขวางในระยะใกล้กว่า 20 ซม. หุ่นยนต์จะสไลด์หลบไปทางขวาโดยอัตโนมัติ
  3. ระบบวิเคราะห์ภาพและปริมาตรน้ำเกลือ (OpenCV - LOLO Version 8): ใช้เทคนิค Computer Vision ในการหาปริมาณน้ำเกลือในถุง โดยใช้ Canny Edge Detection, การทำ Dilation เพื่อหาขอบเขตถุงน้ำเกลือ และวิเคราะห์พิกเซลเพื่อหาระดับน้ำ (Fluid line) จากนั้นคำนวณออกมาเป็นเปอร์เซ็นต์และปริมาตรมิลลิลิตร (ml)
  4. ระบบ Web UI และ Telemetry: สื่อสารกับหน้าจอผ่าน Socket.IO ส่งข้อมูลกลับไปยังหน้าเว็บแบบ Real-time เช่น สถานะหุ่นยนต์, วิดีโอสตรีมมิ่งที่วาดกรอบน้ำเกลือแล้ว, ข้อมูลระยะห่างจาก Sonar และปริมาตรน้ำเกลือ

การทำงาน 8 ขั้นตอน (8-Step Patrol Sequence)

ฟังก์ชัน patrol_worker() จะทำงานแบบอัตโนมัติ (Auto Mode) ตามลำดับดังนี้:

  • ขั้นที่ 1: เดินหน้า 1.5 วินาที พร้อมเปิดระบบหลบหลีกสิ่งกีดขวาง
  • ขั้นที่ 2: เลี้ยวซ้าย 90 องศา
  • ขั้นที่ 3: เดินหน้าต่อ 2.5 วินาที
  • ขั้นที่ 4: ถอยหลัง 2.0 วินาที
  • ขั้นที่ 5: สไลด์ขวาไปที่ เตียงที่ 1 เป็นเวลา 2 วินาที
  • ขั้นที่ 6: เริ่มสแกนเตียงที่ 1 เป็นเวลา 5 วินาที เพื่อหาระดับน้ำเกลือและบันทึกผล
  • ขั้นที่ 7: สไลด์ขวาไปที่ เตียงที่ 2 เป็นเวลา 2 วินาที
  • ขั้นที่ 8: เริ่มสแกนเตียงที่ 2 เป็นเวลา 5 วินาที เพื่อหาระดับน้ำเกลือและส่งผลกลับไปที่ระบบ เมื่อเสร็จสิ้นหุ่นยนต์จะกลับสู่โหมด Standby

ฟังก์ชันที่สำคัญในโค้ด

  • process_frame(frame): รับภาพจากกล้อง แปลงเป็นภาพขาวดำ ทำเบลอ และใช้ Edge Detection ในการคำนวณปริมาณน้ำในถุงน้ำเกลือ คืนค่าภาพที่ถูกวาดกรอบแล้วพร้อมกับค่าระดับน้ำ (ml)
  • drive_forward_avoid(duration_s): สั่งหุ่นยนต์เดินหน้าแบบจำกัดเวลา พร้อมตรวจจับระยะห่าง หากเจอสิ่งกีดขวางใกล้กว่า 20 ซม. จะสั่งสไลด์หลบ
  • turn_left_90() / slide_right_timed(): ควบคุมทิศทางล้อ Mecanum แบบตายตัวตามเวลาที่ตั้งไว้
  • patrol_worker(): Thread หลักที่ใช้รันลำดับขั้น 8 ขั้นตอนให้ต่อเนื่องกัน
  • _custom_process_message(): ฟังก์ชันดักจับ (Monkey-Patch) ภาพจากกล้องก่อนจะส่งขึ้น Web UI เพื่อทำการแทรกกระบวนการวิเคราะห์น้ำเกลือลงในเฟรมวิดีโอ

ภาพรวม

โปรเจกต์ POP เป็นการรวมเอาเทคโนโลยี หุ่นยนต์เคลื่อนที่ (Robotics) และ การประมวลผลภาพ (Computer Vision) เข้าด้วยกัน เพื่อลดภาระของพยาบาลในการเดินตรวจน้ำเกลือตามเตียงผู้ป่วย โดยหุ่นยนต์สามารถทำงานได้ด้วยตัวเองแบบอัตโนมัติตามเส้นทางที่กำหนดไว้

ระบบเสริม: การติดตามวัตถุ (Object Tracking)

นอกจากระบบประมวลผลภาพสำหรับน้ำเกลือแล้ว ยังมีการพัฒนาระบบติดตามวัตถุเพิ่มเติมผ่าน WebRTC (receiver.html) โดยมีฟังก์ชันที่สำคัญดังนี้:

  • การจำวัตถุ (Object Recognition / captureTemplate): ระบบสามารถบันทึกภาพของวัตถุต้นแบบ (Template) โดยดึงพิกเซลจากเฟรมวิดีโอ ณ ตำแหน่งที่ผู้ใช้เลือก เพื่อนำข้อมูลภาพมาใช้เปรียบเทียบและติดตามตำแหน่งวัตถุในเฟรมถัดไป (Template Matching) เมื่อเริ่มจำวัตถุแล้ว สถานะจะแจ้งเตือนว่า "✅ จำวัตถุแล้ว — กำลังติดตาม..."
  • การรีเซ็ต (Reset Tracker / resetTracker): ผู้ใช้สามารถล้างข้อมูลวัตถุที่บันทึกไว้ได้ โดยเมื่อทำการรีเซ็ต ระบบจะล้างค่าตัวแปรข้อมูลภาพ (tmpl = null), หยุดการติดตาม (tracking = false), ลบกรอบภาพที่วาดบนหน้าจอ และคืนค่าสถานะเป็น "กด 📸 จำวัตถุ เพื่อเริ่มติดตามใหม่"
